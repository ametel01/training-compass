# Training Compass

Training Compass is a private, local-first iPhone training app. The current executable contains the protected Gate 0 shell and the local training configuration slices: TMs manages kilogram Training Maxes and per-lift Loading Increments, while Cycle maintains the reusable Schedule Template with audited local persistence. Health data and future cycle execution remain unavailable.

The app targets stable iOS 26 with Swift 6 strict concurrency. Today and Progress remain pre-data destinations; Cycle becomes available after the default schedule's lifts are configured in TMs.

See the [developer documentation](documentation/developer/README.md) for architecture, verification, privacy, migrations, and Acceptance Device evidence.
